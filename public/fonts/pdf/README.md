# PDF embedded fonts

The three `WordQuestSans*.ttf` files are application-specific subsets used by
the offline PDF exporter. They are generated by `scripts/build-pdf-fonts.py`
from:

- Noto Sans SC variable font: https://github.com/notofonts/noto-cjk
- Noto Sans Regular/Bold: https://github.com/notofonts/latin-greek-cyrillic

The subsets contain only characters used by this application's exportable
vocabulary and UI labels. Their internal family and PostScript names were
changed to `WordQuest PDF Sans*` so the modified builds do not use an upstream
reserved font name. Build counts and missing-codepoint checks are recorded in
`font-subset-manifest.json`.
