# 考研英语二历年真题资料库

## 资料库简介

本资料库于 2026-07-13 从公开 GitHub 仓库逐项核对、下载和整理，面向个人备考、阅读精读和后续离线加工。正式区只收录能够确认属于“考研英语二”的文件；年份不定、并非完整真题或仍需人工判断的资料统一放入 `04_待核对资料`，不与正式真题混放。

所有 PDF 均已逐个完成文件存在性、大小、真实格式、可打开性、页数、HTML 伪文件、考试类型、年份和重复性检查。详细结果见 [下载验收报告.md](下载验收报告.md)，逐文件来源见 [05_来源记录/资料来源.csv](05_来源记录/资料来源.csv)，最终文件哈希见 [05_来源记录/SHA256校验值.csv](05_来源记录/SHA256校验值.csv)（校验表自身除外，避免自引用哈希）。

- 真题及参考答案：2010—2017，共 8 份 PDF。

## 文件命名规则

- 真题：`YYYY年考研英语二真题.pdf`
- 真题及答案合卷：`YYYY年考研英语二真题及参考答案.pdf`
- 解析：`YYYY年考研英语二详细解析.pdf`
- 合集：`起始年-结束年考研英语二真题合集（说明）.pdf`
- 阅读加工：`YYYY-TextN.jsonl`、`YYYY-TextN.json`、`YYYY-TextN.md`

只调整外部文件名与目录，不改写 PDF 内部页面。

## 使用与打印说明

1. 做整套模拟时优先使用 `01_单年份真题`，按年份从旧到新计时完成。
2. 完成后再打开 `02_答案与解析`，避免提前看到答案。
3. 连续阅读原文使用 `06_阅读加工/阅读文章`，中英逐句对照使用 `手译版_Markdown`，语法精读使用 `拆句_Markdown`，集中复习难句使用 `长难句_Markdown`；程序数据在 `拆句_JSONL`、`translations` 和 `analyses`。
4. 打印前先在 PDF 阅读器中检查纸张预览，通常选择 A4、“适合可打印区域”或“按 PDF 页面大小”，不要直接拉伸裁切。
5. 多年合集用于连续浏览和备份，不替代单年份版本；两者内容重叠是有意保留，不属于机械重复。
6. 文件损坏或复制后异常时，用 `SHA256校验值.csv` 对照哈希。
