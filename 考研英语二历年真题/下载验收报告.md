## 2. 下载方法与失败切换

1. 使用 GitHub Contents API / Git Tree API 枚举真实文件路径、类型和上游文件大小。
2. 主仓库、备用仓库和讲义仓库均使用 GitHub Raw 地址逐文件下载，并核对 HTTP 成功状态和 API 文件大小。
3. `pfoocc/201_204_kaoyan` 使用 GitHub ZIP 归档取得辅助文本源；整理时只保留科目 204 内容，移除混合的科目 201 和合并 PDF。
4. 整个流程不依赖单一 `git clone` 成功；文件枚举、Raw 和 ZIP 方法可以互相替代。
5. 未使用私人网盘、登录态、付费资源、破解资源或绕过访问控制的方式。
